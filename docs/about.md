# 关于本项目

## 项目目标

实现从 Markdown 文档到公开网站的自动化发布。

## 技术组成

| 工具            | 作用                     |
| --------------- | ------------------------ |
| Markdown        | 编写文档内容             |
| MkDocs Material | 将文档构建成静态网站     |
| GitHub Actions  | 自动执行安装、构建和部署 |
| GitHub Pages    | 托管并提供网站访问地址   |

## 实践体会

本次实践完整走完了从本地编写 Markdown 文档、MkDocs 本地预览，再通过 GitHub‑Actions 实现自动构建部署到 GitHub Pages 的全流程。

在操作过程中，我体会到版本控制 Git 的重要性，每一处文档修改都需要 add、commit、push 才能同步到远程仓库；也理解了自动化工作流的优势：本地写完文档推送之后，不需要手动处理网页构建，平台就自动完成发布。

实践中也遇到不少小问题：例如 Markdown 排版空行问题导致网页渲染错乱、本地 serve 服务异常自动关闭、报告图片因为缩进/全角空格无法正常显示。通过查阅日志、核对配置，逐一排查解决这些问题，加深了对 MkDocs、GitHub Actions 权限与触发规则的理解。

同时也感受到静态文档站点的优势，适合用来整理笔记、实验报告，把本地的文档快速变成可以公开访问的网页。
